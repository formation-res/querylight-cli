# 0.2.6

## What's Changed

- Add `qli package` to write a workspace to a zip archive.
- Allow read-only commands to use a packaged `.zip` workspace directly.
- Allow `qli serve` to load one packaged workspace or a directory of packaged workspaces.
- Add validation that keeps packaged workspaces read-only for commands that mutate workspace data.
- Update CI dependencies and local release guard rails.

**Full Changelog**: https://github.com/formation-res/querylight-cli/compare/0.2.5...0.2.6
